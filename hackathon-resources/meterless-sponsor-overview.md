# Meterless

Local-first context layer for AI agents. Open-source memory, reasoning, world state, intent, and swarm engines.

## What Meterless brings to the hackathon

| What | Details |
|---|---|
| **Agent engines** | The Meterless agent engine guides in this folder: start with **Meterless AGENT ENGINES INDEX**, then **Meterless README** |
| **Template prompts** | Ready-made prompts for the engines: [meterless.ai/engines.html](https://meterless.ai/engines.html) |
| **Open source** | The engines on GitHub: [github.com/Meterless/Meterless](https://github.com/Meterless/Meterless) |
| **Sponsor Tech score** | Meaningful use counts toward Sponsor Tech (10 points) |
